############################################################################################
# Card Game Scripting Guide
# Data Types
# The following data types are used in the scripting system:
#
# int: Integer type
# bool: Boolean type (true or false)
# string: String type
# function: Function type
# Card: Card class
# Effect: Effect class
# Group: Deck or card group class
# table: Table type (used in Lua for arrays or dictionaries)
# nil: Empty type, representing uninitialized or meaningful empty return values
# any: Any type, allowing flexible typing
#
# For clarity, function descriptions use a C-like syntax. Optional parameters with default values are denoted by []. Only meaningful nil parameters or return values are explicitly noted.
# Notes on Filter Condition Functions
# A filter condition function takes a Card as its first parameter and returns a boolean. It is used within filter functions to select cards from a deck that meet specific criteria. The function can accept additional 
# parameters, which are passed from the extra parameters of the filter function. Example:
# function sample_filter(c, atk, def)
#    return c:GetAttack() >= atk and c:GetDefense() >= def
# end
#
# This function returns true if a card c has attack power ≥ atk and defense ≥ def, otherwise false.
# Usage example:
# g = Duel.GetFieldGroup(0, LOCATION_HAND, 0) -- Get Player 1's hand
# fg = g:Filter(sample_filter, nil, 1000, 500) -- Select cards with attack ≥ 1000 and defense ≥ 500
#
# Group.Filter takes three parameters; any additional parameters (starting from the fourth) are passed to the filter condition function.
# Notes on Specifying Locations
# Some functions retrieve cards from specific locations using three parameters: int player, int s, int o.
#
# s: The player's own side locations.
# o: The opponent's side locations relative to the player.
#
# Example:
# Duel.GetFieldGroup(0, LOCATION_GRAVE, LOCATION_MZONE)
#
# This returns all cards in Player 0's graveyard and Player 1's monster zone.
# Notes on Descriptions
# The scripting system does not use strings directly for prompt text. Instead, an integer (int desc) is used to look up descriptions:
#
# For desc < 2048, the system looks in string.conf, where common prompt texts are defined (often in constant.lua).
# For desc > 10000, the system retrieves descriptions from the card database, typically specified using aux.Stringid().
#
# Obsolete Functions
#
# void Duel.ReplaceAttacker(Card c): Replaced the current attacking card for the damage phase (no longer exists).
# void Duel.ReplaceAttackTarget(Card c): Reserved, but does not exist.
#
# Zone-Related Information
#
# Player's field: Main monster zones are numbered 0–4 from left to right. Extra monster zones are 5–6. The value 0x7f represents all main and extra monster zones.
# Zone values: Zones are represented as powers of 2. To determine the zone number, use math.log(zone, 2).
# Opponent's zones: Opponent zone values are left-shifted by 16 bits.
#
# Binary representation for clarity:
#
# 0x7f = 0111 1111 (binary: 1111 1110 when reversed):
# Bits 0–4: Main monster zones (0–4).
# Bit 5: Left extra monster zone.
# Bit 6: Right extra monster zone.
#
#
#
# Zone mappings:
#
# Zone 0: 0x1 = 0000 0001 (binary)
# Zone 1: 0x2 = 0000 0010
# Zone 2: 0x4 = 0000 0100
# Zone 3: 0x8 = 0000 1000
# Zone 4: 0x10 = 0001 0000
# Zone 5: 0x20 = 0010 0000
# Zone 6: 0x40 = 0100 0000

========== Card ==========
●bool Card.AddCounter(Card c, int countertype, int count[, int singly=false])
Place count countertype counters on card c, if singly=true, add them one by one up to the limit


●void Card.AddMonsterAttribute(Card c, int type[, int attribute, int race, int level, int atk, int def])
Add monster stats to Spell/Trap card c, type is the monster type, cannot be a monster without a Level
Note: Values recorded in the database are considered original values


●void Card.AssumeProperty(Card c,int assume_type, int assume_value)
Use c's assume_type value as assume_value (e.g., Genome Fighter)
assume_type is one of the following types:
ASSUME_CODE:      Card code
ASSUME_TYPE:      Type
ASSUME_LEVEL:     Level
ASSUME_RANK:      Rank
ASSUME_ATTRIBUTE: Attribute
ASSUME_RACE:      Race
ASSUME_ATTACK:    ATK
ASSUME_DEFENSE:   DEF


●void Card.CancelCardTarget(Card c1, Card c2)
Cancel card c2 as the continuous target of card c1


●void Card.CancelToGrave(Card c[, bool cancel=true])
Cancel the confirmed-to-Graveyard state, if cancel=false, reset the confirmed-to-Graveyard state
Note: The confirmed-to-Graveyard state refers to the state of Spell/Trap cards activated on the field that do not remain on the field
Cards in the confirmed-to-Graveyard state cannot return to the hand or Deck and are sent to the Graveyard at the end of the chain
This function cancels this state to keep the card on the field, used for cards like Light of Intervention and Scrap-Iron Scarecrow


●Effect[,Group,int,int,Effect,int,int] Card.CheckActivateEffect(Card c, bool neglect_con, bool neglect_cost, bool copy_info)
Return the 'card activation' effect of card c with correct activation timing, if neglect_con=true, ignore activation conditions, if neglect_cost=true, ignore activation cost
If copy_info=false or the effect has free timing, return only the effect e
Otherwise, also return the trigger timing information for the effect: e, eg, ep, ev, re, r, rp


●bool Card.CheckEquipTarget(Card c1, Card c2)
Check if card c2 is a valid Equip target for card c1


●bool Card.CheckFusionMaterial(Card c[, Group g|nil, Card gc|nil, int chkf=PLAYER_NONE])
Check if the field [or g] contains a group of Fusion Materials required for c [including gc]


●bool Card.CheckFusionSubstitute(Card c, Card fc)
Check if card c can substitute for the named material of Fusion Monster fc


●bool Card.CheckRemoveOverlayCard(Card c, int player, int count, int reason)
Check if player can remove at least count cards stacked under c for reason


●Card Card.CheckUnionTarget(Card c, Card ec)
Check if ec is a valid Union Equip target for c. Checks for EFFECT_UNION_LIMIT and new/old Union effects.


●bool Card.CheckUniqueOnField(Card c,int check_player[, int check_location=LOCATION_ONFIELD, Card icard|nil])
Check the uniqueness of card c on check_player's field

●void Card.CreateEffectRelation(Card c, Effect e)
Establish a link between card c and effect e


●void Card.CreateRelation(Card c1, Card c2, int reset_flag)

●void Card.EnableCounterPermit(Card c, int countertype[, int location])
Allow card c [at location] to place countertype counters that require 'can be placed' permission

●void Card.EnableReviveLimit(Card c)

●bool aux.damcon1(Effect e, int tp, Group eg, int ep, int ev, Effect re, int r, int rp)

function aux.damcon1(e, tp, eg, ep, ev, re, r, rp)
  local e1=Duel.IsPlayerAffectedByEffect(tp, EFFECT_REVERSE_DAMAGE)
  local e2=Duel.IsPlayerAffectedByEffect(tp, EFFECT_REVERSE_RECOVER)
  local rd=e1 and not e2
  local rr=not e1 and e2
  local ex,cg,ct,cp,cv=Duel.GetOperationInfo(ev, CATEGORY_DAMAGE)
  if ex and (cp==tp or cp==PLAYER_ALL) and not rd and not Duel.IsPlayerAffectedByEffect(tp, EFFECT_NO_EFFECT_DAMAGE) then
    return true
  end
  ex,cg,ct,cp,cv=Duel.GetOperationInfo(ev, CATEGORY_RECOVER)
  return ex and (cp==tp or cp==PLAYER_ALL) and rr and not Duel.IsPlayerAffectedByEffect(tp, EFFECT_NO_EFFECT_DAMAGE)
end

flag for puzzles: DUEL_ATTACK_FIRST_TURN+DUEL_SIMPLE_AI
flag for Master Rule 1: DUEL_OBSOLETE_RULING
rule=4 is the new Master Rule


●void Debug.ReloadFieldEnd()
End field setup


●void Debug.SetAIName(string name)
Set the AI's name, maximum length 100 characters (1 Chinese character counts as 2 characters)


●void Debug.SetPlayerInfo(int playerid, int lp, int startcount, int drawcount)
Set player information: Life Points to lp, initial hand cards to startcount, draw drawcount cards per turn
In puzzles, playerid: self=0, opponent=1


●void Debug.ShowHint(string msg)
Display a message prompt box, maximum length 1024 characters (1 Chinese character counts as 2 characters)
Note: Only takes effect locally, not on the server side


●void initial_effect(Card c)
Called when loading a card
Typically used to register initial card effects and set revival restrictions, etc.
