# Group.GetSum

## Signature

```lua
Group.GetSum(Group g, function f, ... any) -> int
```

## Description

Calls f for each card in g, forwards any extra arguments, and returns the sum of the integer values produced.

## Parameters

- `g` `Group`
- `f` `function`
- `...` `any`
