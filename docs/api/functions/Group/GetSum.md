# Group.GetSum

## Signature

```lua
Group.GetSum(Group g, function f, ... any) -> int
```

## Description

Calculates the sum of the values ​​of all cards in g, f is the value function for each card, starting with the third parameter as an additional parameter

- `f` `function`
- `...` `any`
