# Auxiliary.RitualCheckGreater

## Signature

```lua
Auxiliary.RitualCheckGreater(Group g, Card c, int lv) -> bool
```

## Description

Checks whether g's Ritual Levels are greater than or equal to lv for c.

## Parameters

- `g` `Group`
- `c` `Card`
- `lv` `int`

## Returns

- `bool` - true if g reaches at least lv.
