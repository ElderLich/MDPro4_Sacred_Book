# Auxiliary.EnableSpiritReturn

## Signature

```lua
Auxiliary.EnableSpiritReturn(Card c, any event1, ... any) -> void
```

## Description

Add an effect to c for Spirit Monsters to return to the hand during the End Phase of turns when events event1,... occur

## Parameters

- `c` `Card`
- `event1` `any`
- `...` `any`
