# Auxiliary.IsCodeOrListed

## Signature

```lua
Auxiliary.IsCodeOrListed(Card c, int code) -> bool
```

## Description

Returns true if c's current code matches code or code is registered in c's listed-code table.

## Parameters

- `c` `Card`
- `code` `int`

## Returns

- `bool` - true if c has or lists code.
