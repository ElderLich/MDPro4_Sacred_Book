# Auxiliary.LUncompatibilityFilter

## Signature

```lua
Auxiliary.LUncompatibilityFilter(Card c, Group sg, Card lc, int tp) -> bool
```

## Description

Returns true when c is not compatible with the other selected Link Materials.

## Parameters

- `c` `Card`
- `sg` `Group`
- `lc` `Card`
- `tp` `int`

## Returns

- `bool` - true if c is incompatible with the rest of sg.
