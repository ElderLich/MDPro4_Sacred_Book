# Auxiliary.GetMinSynchroLevel

## Signature

```lua
Auxiliary.GetMinSynchroLevel(Card c, Card syncard) -> int
```

## Description

Returns the smallest Synchro Level value c can provide for syncard, including packed alternative Synchro Levels.

## Parameters

- `c` `Card`
- `syncard` `Card`

## Returns

- `int` - Smallest Synchro Level value c can provide.
