# Auxiliary.Stringid

## Signature

```lua
Auxiliary.Stringid(int code, int id) -> int
```

## Description

Returns the card-string id for card code and string index id. The index starts at 0 and is commonly passed to Effect.SetDescription, Duel.Hint, or selection prompts.
