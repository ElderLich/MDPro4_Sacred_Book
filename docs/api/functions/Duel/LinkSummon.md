# Duel.LinkSummon

## Signature

```lua
Duel.LinkSummon(int player, Card pcard, [Group|nil mg], [Card lcard], [int minc], [int maxc]) -> void
```

## Description

Have player Link Summon pcard using \[minc to maxc cards from mg, excluding lcard\] as materials

## Parameters

- `player` `int`
- `pcard` `Card`
- `mg` `Group|nil` optional
- `lcard` `Card` optional
- `minc` `int` optional
- `maxc` `int` optional
