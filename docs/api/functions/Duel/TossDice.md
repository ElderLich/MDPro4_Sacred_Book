# Duel.TossDice

## Signature

```lua
Duel.TossDice(int player, int count1, [int count2]) -> ...
```

## Description

Let the player to cast count1 dice\[, 1-player to vote count2 dice\] (count1 + count2 &lt;= 5)
The return value is count1 + count2 results, 1-6

## Parameters

- `player` `int`
- `count1` `int`
- `count2` `int` optional
