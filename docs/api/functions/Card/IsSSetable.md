# Card.IsSSetable

## Signature

```lua
Card.IsSSetable(Card c, [bool ignore_field]) -> bool
```

## Description

Checks whether c can be Set in a Spell & Trap Zone. If ignore_field is true, available zone checks are ignored.

## Parameters

- `c` `Card`
- `ignore_field` `bool` optional - default: false

## Returns

- `bool`
