# Card.GetLinkedZone

## Signature

```lua
Card.GetLinkedZone(Card c, [int player]) -> int
```

## Description

Returns the linked-zone bitmask generated by c.
By default the bitmask is from c's controller perspective. Passing player converts the mask to that player's perspective.
Use bit helpers such as bit.extract or bit.band when checking whether a specific sequence is pointed to.

## Parameters

- `c` `Card`
- `player` `int` optional - Perspective player for the returned zone mask. Default: c's controller.

## Returns

- `int` - Linked-zone bitmask from the requested perspective.
