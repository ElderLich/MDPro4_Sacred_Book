# Card.IsAbleToHand

## Signature

```lua
Card.IsAbleToHand(Card c) -> bool
```

## Description

Check whether c can hand
Note: This function returns false only if the card or player is affected by the effect of being unable to join the hand (such as Ray King)

## Parameters

- `c` `Card`

## Returns

- `bool`
