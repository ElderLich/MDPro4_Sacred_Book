# MDPro3 Sacred Book

Documentation and data-generation tools for MDPro3/YGOPro Lua card scripting.

## Generate

```powershell
python Tools\FunctionDocs\generate_function_docs.py
```

Generated references are written to `Generated/FunctionDocs/`, including DataEditorX-compatible tooltip files and a wiki tree under `Generated/FunctionDocs/wiki/`.

## Wiki Preview

```powershell
npm install
npm run docs:dev
```
