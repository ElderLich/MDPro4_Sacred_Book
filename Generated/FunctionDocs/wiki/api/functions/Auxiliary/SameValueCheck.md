# Auxiliary.SameValueCheck

## Signature

```lua
Auxiliary.SameValueCheck(Group g, function f) -> bool
```

## Description

Checks whether every card in g shares at least one bit returned by f; groups of 0 or 1 card return true.

## Parameters

- `g` `Group`
- `f` `function`

## Returns

- `bool`
