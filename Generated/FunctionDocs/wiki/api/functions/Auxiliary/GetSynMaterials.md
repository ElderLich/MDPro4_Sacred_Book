# Auxiliary.GetSynMaterials

## Signature

```lua
Auxiliary.GetSynMaterials(int tp, Card syncard) -> Group
```

## Description

Returns the available Synchro Materials for tp and syncard, including valid hand materials when any field material enables hand Synchro use.

## Parameters

- `tp` `int`
- `syncard` `Card`

## Returns

- `Group` - Available Synchro Materials.
