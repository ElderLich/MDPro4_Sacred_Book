# Auxiliary.AdjacentFilter

## Signature

```lua
Auxiliary.AdjacentFilter(Card c, int i, int j) -> bool
```

## Description

Returns whether c's global field coordinate is directly adjacent to (i, j), sharing an edge rather than a diagonal.

## Parameters

- `c` `Card`
- `i` `int`
- `j` `int`

## Returns

- `bool`
