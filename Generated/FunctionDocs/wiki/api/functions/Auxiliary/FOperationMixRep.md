# Auxiliary.FOperationMixRep

## Signature

```lua
Auxiliary.FOperationMixRep(bool insf, bool sub, function fun1, int minc, int maxc, ... function) -> function
```

## Description

Returns the operation function for mixed Fusion Material procedures with a repeated material slot; it lets the player build a valid material group and stores it.

## Parameters

- `insf` `bool`
- `sub` `bool`
- `fun1` `function`
- `minc` `int`
- `maxc` `int`
- `...` `function`

## Returns

- `function` - Operation function for a mixed-repeat Fusion Material procedure.
