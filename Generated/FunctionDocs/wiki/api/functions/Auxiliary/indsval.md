# Auxiliary.indsval

## Signature

```lua
Auxiliary.indsval(Effect e, Effect re, int rp) -> bool
```

## Description

Value helper for self-protection from effect destruction; it returns true when the reason player is the handler's player.

## Parameters

- `e` `Effect`
- `re` `Effect`
- `rp` `int`

## Returns

- `bool`
