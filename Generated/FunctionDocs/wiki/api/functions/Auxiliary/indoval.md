# Auxiliary.indoval

## Signature

```lua
Auxiliary.indoval(Effect e, Effect re, int rp) -> bool
```

## Description

Value helper for indestructibility against opponent's effects; it returns true when rp is the opponent of e's handler player.

## Parameters

- `e` `Effect`
- `re` `Effect`
- `rp` `int`

## Returns

- `bool`
