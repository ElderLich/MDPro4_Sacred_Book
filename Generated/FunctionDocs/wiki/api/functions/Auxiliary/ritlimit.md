# Auxiliary.ritlimit

## Signature

```lua
Auxiliary.ritlimit(Effect e, Effect se, int sp, int st) -> bool
```

## Description

Special Summon condition helper that returns true only when the Summon Type contains SUMMON_TYPE_RITUAL.

- `se` `Effect`
- `sp` `int`
- `st` `int`
