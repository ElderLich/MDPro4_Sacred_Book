# Auxiliary.DrytronSpSummonOperation

## Signature

```lua
Auxiliary.DrytronSpSummonOperation(function func) -> void
```

## Description

Returns the shared Drytron operation wrapper. It Special Summons the handler in face-up Defense Position, completes its procedure, then calls func(e,tp).
