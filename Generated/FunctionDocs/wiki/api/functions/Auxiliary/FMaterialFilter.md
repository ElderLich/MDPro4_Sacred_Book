# Auxiliary.FMaterialFilter

## Signature

```lua
Auxiliary.FMaterialFilter(Card c, Effect e, int tp) -> bool
```

## Description

Default Fusion Material filter for Fusion effects; returns whether c can be used as Fusion Material.

## Parameters

- `c` `Card`
- `e` `Effect`
- `tp` `int`

## Returns

- `bool` - true if c can be used as Fusion Material.
