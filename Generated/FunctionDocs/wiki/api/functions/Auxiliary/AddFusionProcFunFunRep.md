# Auxiliary.AddFusionProcFunFunRep

## Signature

```lua
Auxiliary.AddFusionProcFunFunRep(Card c, function|table f1, function|table f2, int minc, int maxc, bool insf) -> void
```

## Description

Registers a Fusion procedure requiring f1 plus between minc and maxc materials that satisfy f2.

- `c` `Card`
- `f1` `function|table`
- `f2` `function|table`
- `minc` `int`
- `maxc` `int`
