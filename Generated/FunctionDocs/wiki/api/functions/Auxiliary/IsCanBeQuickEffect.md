# Auxiliary.IsCanBeQuickEffect

## Signature

```lua
Auxiliary.IsCanBeQuickEffect(Card c, int tp, int code) -> bool
```

## Description

Checks whether player tp is affected by code, code has a registered quick-effect filter, and that filter accepts c.

## Parameters

- `c` `Card`
- `tp` `int`
- `code` `int`

## Returns

- `bool`
