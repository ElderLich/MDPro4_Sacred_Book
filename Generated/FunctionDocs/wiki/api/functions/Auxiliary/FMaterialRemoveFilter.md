# Auxiliary.FMaterialRemoveFilter

## Signature

```lua
Auxiliary.FMaterialRemoveFilter(Card c, Effect e, int tp) -> bool
```

## Description

Default Graveyard-material filter for Fusion effects that banish materials; returns whether c can be banished.

## Parameters

- `c` `Card`
- `e` `Effect`
- `tp` `int`

## Returns

- `bool` - true if c can be banished.
