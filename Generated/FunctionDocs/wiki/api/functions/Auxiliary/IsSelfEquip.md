# Auxiliary.IsSelfEquip

## Signature

```lua
Auxiliary.IsSelfEquip(Card c, int id) -> bool
```

## Description

Checks whether c has an equipped card carrying flag effect id, which marks equipment created by that card's own effect.

- `c` `Card`
- `id` `int`

## Returns
