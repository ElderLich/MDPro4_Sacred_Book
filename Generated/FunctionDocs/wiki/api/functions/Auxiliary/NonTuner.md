# Auxiliary.NonTuner

## Signature

```lua
Auxiliary.NonTuner(function f, ... any) -> void
```

## Description

Returns a non-Tuner material filter that also applies f when f is supplied.
Extra arguments are captured now and passed to f after the Card argument.

## Parameters

- `f` `function`
- `...` `any`
