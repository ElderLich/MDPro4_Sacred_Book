# Auxiliary.DrytronCounterFilter

## Signature

```lua
Auxiliary.DrytronCounterFilter(Card c) -> void
```

## Description

Activity-counter filter for the shared Drytron Special Summon effect. It returns true for cards that cannot be Normal Summoned/Set, so the counter can detect whether tp Special Summoned a monster that can be Normal Summoned/Set this turn.

## Parameters

- `c` `Card`
