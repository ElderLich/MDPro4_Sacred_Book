# Auxiliary.ArsMagnaFilter

## Signature

```lua
Auxiliary.ArsMagnaFilter(Card c) -> bool
```

## Description

Checks whether c originally belongs to set 0x1e6. Used by the Ars Magna field effect in Auxiliary.quick_effect_filter to determine which effects become Quick Effects.

- `c` `Card`
