# Auxiliary.MZoneSequence

## Signature

```lua
Auxiliary.MZoneSequence(int seq) -> void
```

## Description

Return the Monster Zone sequence number; from left to right, zones are 0-4; for Extra Monster Zones, return left as 1 or right as 3

## Parameters

- `seq` `int`
