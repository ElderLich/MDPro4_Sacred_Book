# Auxiliary.UrsarcticReleaseFilter

## Signature

```lua
Auxiliary.UrsarcticReleaseFilter(Card c) -> bool
```

## Description

Cost filter for the shared Ursarctic Special Summon effect. It accepts Level 7 or higher monsters in the hand.

## Parameters

- `c` `Card`

## Returns

- `bool` - true if c is a Level 7 or higher monster in the hand.
