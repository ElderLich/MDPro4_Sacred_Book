# Auxiliary.GetColumn

## Signature

```lua
Auxiliary.GetColumn(Card c, [int p]) -> int
```

## Description

Returns c's column index from player p's viewpoint, or NULL_VALUE when c has no field column.

## Parameters

- `c` `Card`
- `p` `int` optional - default: 0

## Returns

- `int`
