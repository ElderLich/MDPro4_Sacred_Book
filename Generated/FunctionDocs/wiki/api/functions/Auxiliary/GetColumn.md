# Auxiliary.GetColumn

## Signature

```lua
Auxiliary.GetColumn(Card c, [int p]) -> int
```

## Description

Return the column sequence number of card c from player's perspective, excluding the Field Zone; from left to right, columns are 0-4

## Parameters

- `c` `Card`
- `p` `int` optional - default: 0

## Returns

- `int`
