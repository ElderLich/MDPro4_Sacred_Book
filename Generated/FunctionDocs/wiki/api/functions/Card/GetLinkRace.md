# Card.GetLinkRace

## Signature

```lua
Card.GetLinkRace(Card c, [int player]) -> int
```

## Description

Returns the Race c uses as Link Material for player, defaulting to the current reason player.

## Parameters

- `c` `Card`
- `player` `int` optional - default: current reason player

## Returns

- `int`
