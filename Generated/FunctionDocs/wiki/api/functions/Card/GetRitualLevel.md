# Card.GetRitualLevel

## Signature

```lua
Card.GetRitualLevel(Card c, Card rc) -> int
```

## Description

Returns the ritual liberation level for rc ritual monsters
This function returns the same value as Card.GetLevel(c) except for certain cards such as ritual objects

## Parameters

- `c` `Card`
- `rc` `Card`

## Returns

- `int`
