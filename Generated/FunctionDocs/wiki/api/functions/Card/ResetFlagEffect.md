# Card.ResetFlagEffect

## Signature

```lua
Card.ResetFlagEffect(Card c, int code) -> void
```

## Description

Resets all flag effects on c with code.

## Parameters

- `c` `Card` - Card whose matching flag effects are reset.
- `code` `int` - Flag-effect code to clear.
