# Card.IsCanBeEffectTarget

## Signature

```lua
Card.IsCanBeEffectTarget(Card c, [Effect e]) -> bool
```

## Description

Checks whether c can be targeted by e, or by the current reason effect when e is omitted.

## Parameters

- `c` `Card`
- `e` `Effect` optional

## Returns

- `bool`
