# Card.AddCounter

## Signature

```lua
Card.AddCounter(Card c, int countertype, int count, [int singly]) -> bool
```

## Description

为c放置count个countertype类型的指示物，singly为true表示逐个添加至上限为止

## Parameters

- `c` `Card`
- `countertype` `int`
- `count` `int`
- `singly` `int` optional - default: false

## Returns

- `bool`
