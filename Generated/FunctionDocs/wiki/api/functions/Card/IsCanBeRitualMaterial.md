# Card.IsCanBeRitualMaterial

## Signature

```lua
Card.IsCanBeRitualMaterial(Card c, [Card|nil sc]) -> bool
```

## Description

Checks whether c can be used as Ritual Material for sc; pass nil when no Ritual Monster is being checked.

## Parameters

- `c` `Card`
- `sc` `Card|nil` optional

## Returns

- `bool`
