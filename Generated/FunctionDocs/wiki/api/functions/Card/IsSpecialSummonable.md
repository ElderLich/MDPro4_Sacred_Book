# Card.IsSpecialSummonable

## Signature

```lua
Card.IsSpecialSummonable(Card c, [int sum_type]) -> bool
```

## Description

Checks whether c can be Special Summoned by player under sum_type, defaulting to 0 and using the current reason player.

## Parameters

- `c` `Card`
- `sum_type` `int` optional

## Returns

- `bool`
