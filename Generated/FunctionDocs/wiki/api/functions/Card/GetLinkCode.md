# Card.GetLinkCode

## Signature

```lua
Card.GetLinkCode(Card c) -> int,...?
```

## Description

Returns c's Link Material codes: current code, second code when present, then EFFECT_ADD_LINK_CODE values.

## Parameters

- `c` `Card`

## Returns

- `int` - Current code.
- `...?` - Additional Link Material code values, if any.
