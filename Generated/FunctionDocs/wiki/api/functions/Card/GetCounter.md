# Card.GetCounter

## Signature

```lua
Card.GetCounter(Card c, int countertype) -> int
```

## Description

返回c上的countertype类型的指示物的数量， countertype=0 则返回c上所有类型的指示物数量之和

## Parameters

- `c` `Card`
- `countertype` `int`

## Returns

- `int`
