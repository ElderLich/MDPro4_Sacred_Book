# Card.GetOriginalLevel

## Signature

```lua
Card.GetOriginalLevel(Card c) -> int
```

## Description

Returns c's original Level from card data, or 0 for Xyz Monsters, Link Monsters, and cards marked with STATUS_NO_LEVEL.

## Parameters

- `c` `Card`

- `int`
