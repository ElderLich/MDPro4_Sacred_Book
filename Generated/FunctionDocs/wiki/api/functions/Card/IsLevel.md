# Card.IsLevel

## Signature

```lua
Card.IsLevel(Card c, int level1, [int level2], [... int]) -> bool
```

## Description

Checks whether c's current Level equals any supplied level value.
nil level arguments are ignored.

## Parameters

- `c` `Card`
- `level1` `int`
- `level2` `int` optional
- `...` `int` optional

## Returns

- `bool`
