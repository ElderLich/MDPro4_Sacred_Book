# Card.SetHint

## Signature

```lua
Card.SetHint(Card c, int type, int value) -> void
```

## Description

Sends a client card-hint message for c with hint type and value; types at or above CHINT_DESC_ADD are ignored.

## Parameters

- `c` `Card`
- `type` `int`
- `value` `int`
