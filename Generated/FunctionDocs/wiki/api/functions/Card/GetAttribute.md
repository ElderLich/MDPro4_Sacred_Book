# Card.GetAttribute

## Signature

```lua
Card.GetAttribute(Card c) -> int
```

## Description

Returns c's current Attribute bitmask.
Cards treated as having multiple Attributes can return a bitwise combination of ATTRIBUTE_* values.

## Parameters

- `c` `Card`

## Returns

- `int`
