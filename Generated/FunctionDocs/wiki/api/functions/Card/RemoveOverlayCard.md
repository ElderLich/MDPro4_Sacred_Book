# Card.RemoveOverlayCard

```lua
Card.RemoveOverlayCard(Card c, int player, int min, int max, int reason) -> int
```

以reason为原因，让玩家player移除c叠放的min-max张卡，返回值表示移除的数量

- `reason` `int`
