# Card.IsSynchroType

## Signature

```lua
Card.IsSynchroType(Card c, int type) -> bool
```

## Description

Check if card c, when used as Synchro Material, has type type (unlike IsType, for monster cards in the Spell/Trap Zone, it uses their original type for judgment)

## Parameters

- `c` `Card`
- `type` `int`

## Returns

- `bool`
