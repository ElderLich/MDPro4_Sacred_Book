# Card.SetStatus

## Signature

```lua
Card.SetStatus(Card c, int status, bool enable) -> void
```

## Description

Sets or clears status on c.
This is an internal-status helper. The binding does nothing while c is copying another card's effect.

## Parameters

- `c` `Card`
- `status` `int`
- `enable` `bool`
