# Card.SetMaterial

## Signature

```lua
Card.SetMaterial(Card c, [Group|nil g]) -> void
```

## Description

Sets g as c's material group for a Summon, or clears c's materials when g is nil.

## Parameters

- `c` `Card`
- `g` `Group|nil` optional
