# Card.GetActivateEffect

## Signature

```lua
Card.GetActivateEffect(Card c) -> Effect,...?
```

## Description

Returns the effect of the "card firing" of c, that is, the effect of type EFFECT_TYPE_ACTIVATE
Only for magic and traps

## Parameters

- `c` `Card`

## Returns

- `Effect`
- `...?` - Effect
