# Card.GetActivateEffect

## Signature

```lua
Card.GetActivateEffect(Card c) -> Effect,...?
```

## Description

Returns c's activation effect, the effect with type EFFECT_TYPE_ACTIVATE. This is mainly used for Spell/Trap Cards.

## Parameters

- `c` `Card`

## Returns

- `Effect`
- `...?` - Effect
