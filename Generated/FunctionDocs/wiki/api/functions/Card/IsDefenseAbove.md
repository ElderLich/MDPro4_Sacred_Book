# Card.IsDefenseAbove

## Signature

```lua
Card.IsDefenseAbove(Card c, int def) -> bool
```

## Description

Checks whether c has current DEF greater than or equal to def.
Link Monsters and cards that are not monsters or currently treated as monsters return false.

## Parameters

- `c` `Card`
- `def` `int`

## Returns

- `bool`
