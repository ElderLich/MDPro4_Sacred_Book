# Card.ReverseInDeck

## Signature

```lua
Card.ReverseInDeck(Card c) -> void
```

## Description

Marks c face-up while it is in the Deck.
If c is the current top card of the Main Deck, the core also sends the top-of-Deck update to the client.

## Parameters

- `c` `Card`
