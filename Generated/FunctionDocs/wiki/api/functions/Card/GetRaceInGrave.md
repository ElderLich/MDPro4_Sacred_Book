# Card.GetRaceInGrave

## Signature

```lua
Card.GetRaceInGrave(Card c, [int reasonPlayer]) -> int
```

## Description

检查c在墓地中会变成什么种族。
第二个参数可选，指示假设送去墓地是由于哪个玩家。

## Parameters

- `c` `Card`
- `reasonPlayer` `int` optional

## Returns

- `int`
