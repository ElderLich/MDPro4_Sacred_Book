# Card.GetBattleTarget

## Signature

```lua
Card.GetBattleTarget(Card c) -> Card|nil
```

## Description

Returns the monster currently battling c, or nil if c is not the current attacker or attack target.

## Parameters

- `c` `Card`

## Returns

- `Card|nil` - The monster battling c, or nil.
