# Duel.ChangeAttacker

## Signature

```lua
Duel.ChangeAttacker(Card c, [bool ignore_count]) -> void
```

## Description

将攻击怪兽变为c
若 ignore_count=true 则原来的攻击怪兽不视为攻击过

## Parameters

- `c` `Card`
- `ignore_count` `bool` optional - default: false
