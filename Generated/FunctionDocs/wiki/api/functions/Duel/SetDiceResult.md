# Duel.SetDiceResult

## Signature

```lua
Duel.SetDiceResult([int res1], [int res2], [int res3], [int res4], [int res5]) -> void
```

## Description

Sets the five stored dice-result slots; missing or out-of-range values are stored as 1.

## Parameters

- `res1` `int` optional
- `res2` `int` optional
- `res3` `int` optional
- `res4` `int` optional
- `res5` `int` optional
