# Duel.GetCounter

## Signature

```lua
Duel.GetCounter(int player, int s, int o, int countertype) -> int
```

## Description

返回场上存在的countertype类型的指示物的数量
s表示对player来说的己方的可移除指示物的位置，o表示对player来说的对方的可移除指示物的位置

## Parameters

- `player` `int`
- `s` `int`
- `o` `int`
- `countertype` `int`

## Returns

- `int`
