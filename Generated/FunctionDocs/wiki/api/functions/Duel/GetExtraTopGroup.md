# Duel.GetExtraTopGroup

## Signature

```lua
Duel.GetExtraTopGroup(int player, int count) -> Group
```

## Description

Returns a Group containing up to count cards from the top of player's Extra Deck, after the face-up Pendulum section.

## Parameters

- `player` `int`
- `count` `int`

## Returns
