# Duel.GetTurnCount

## Signature

```lua
Duel.GetTurnCount([int player]) -> int
```

## Description

Returns the current turn count.
With no player argument, this returns the duel-wide turn number; with player 0 or 1, it returns that player's personal turn count.

## Parameters

- `player` `int` optional

## Returns

- `int`
