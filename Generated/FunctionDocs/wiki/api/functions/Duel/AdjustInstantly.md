# Duel.AdjustInstantly

## Signature

```lua
Duel.AdjustInstantly([Card c]) -> void
```

## Description

Runs immediate field adjustment.
When c is supplied, the core refreshes disable relations for cards related to c before adjusting the field.

## Parameters

- `c` `Card` optional
