## Signature

```lua
Duel.GetTributeCount(Card c, [Group mg], [bool ex]) -> int
```

## Description

Returns the number of available Tribute candidates for target, optionally restricted to mg and extra handling.

- `mg` `Group` optional
- `ex` `bool` optional - default: false
