# Duel.RockPaperScissors

## Signature

```lua
Duel.RockPaperScissors([bool repeated]) -> int
```

## Description

猜拳，若 repeated=false 则只猜一次；否则就是直到分出胜负为止。返回胜利的玩家号码

## Parameters

- `repeated` `bool` optional - default: true

## Returns

- `int`
