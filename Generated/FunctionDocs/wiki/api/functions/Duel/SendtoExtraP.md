# Duel.SendtoExtraP

## Signature

```lua
Duel.SendtoExtraP(Card|Group targets, int player, int reason) -> int
```

## Description

Sends cards to player-side Extra Deck face-up for reason and returns the number of cards moved.

## Parameters

- `targets` `Card|Group`
- `player` `int`
- `reason` `int`

## Returns

- `int`
