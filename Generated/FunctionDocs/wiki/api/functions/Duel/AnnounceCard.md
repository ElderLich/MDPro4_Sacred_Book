# Duel.AnnounceCard

## Signature

```lua
Duel.AnnounceCard(int player, [int opcode1], [... int]) -> int
```

## Description

Lets player declare a card code matching the optional opcode/filter expression and returns the selected code.

## Parameters

- `player` `int`
- `opcode1` `int` optional
- `...` `int` optional

## Returns

- `int`
