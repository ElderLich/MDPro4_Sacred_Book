# Duel.NegateEffect

## Signature

```lua
Duel.NegateEffect(int chainc, [bool forced]) -> bool
```

## Description

Attempts to negate the effect of chainc and returns true if it succeeds. forced requests a forced disable.

## Parameters

- `chainc` `int`
- `forced` `bool` optional

## Returns

- `bool`
