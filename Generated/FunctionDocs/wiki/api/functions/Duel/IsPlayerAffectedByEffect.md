# Duel.IsPlayerAffectedByEffect

## Signature

```lua
Duel.IsPlayerAffectedByEffect(int player, int code) -> Effect|nil,...
```

## Description

检查player是否受到种类为code的效果影响，如果有就返回该效果，没有则返回nil

- `player` `int`
- `code` `int`

## Returns

- `Effect|nil`
- `...`
