# Duel.IsPlayerAffectedByEffect

## Signature

```lua
Duel.IsPlayerAffectedByEffect(int player, int code) -> Effect|nil,...
```

## Description

Returns an effect affecting player with code, or nil if no matching effect exists. Some effects may return additional values.

## Parameters

- `player` `int`
- `code` `int`

## Returns

- `Effect|nil`
- `...`
