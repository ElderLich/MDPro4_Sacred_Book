# Duel.IsPlayerCanMSet

## Signature

```lua
Duel.IsPlayerCanMSet(int player, [int sumtype], [Card scard]) -> bool
```

## Description

Checks whether player can Set monsters at all, or whether player can Set c with summon type sumtype.
