# Duel.GetLinkedGroup

## Signature

```lua
Duel.GetLinkedGroup(int player, int s, int o) -> Group|nil
```

## Description

Returns a Group of cards in player-relative locations s and o that are linked.

## Parameters

- `player` `int`
- `s` `int`
- `o` `int`

## Returns

- `Group|nil` - Linked cards, or nil if player is invalid.
