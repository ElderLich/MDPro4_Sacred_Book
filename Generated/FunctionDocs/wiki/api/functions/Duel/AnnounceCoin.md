# Duel.AnnounceCoin

## Signature

```lua
Duel.AnnounceCoin(int player) -> int
```

## Description

Lets player choose one of the built-in coin-side options and returns the zero-based option index.

## Parameters

- `player` `int`

## Returns

- `int` - Zero-based option index.
