# Duel.DiscardDeck

## Signature

```lua
Duel.DiscardDeck(int player, int count, int reason) -> int
```

## Description

Sends count cards from the top of player's Deck to the Graveyard for reason, and returns the number actually moved.

## Parameters

- `player` `int`
- `count` `int`
- `reason` `int`

## Returns

- `int`
