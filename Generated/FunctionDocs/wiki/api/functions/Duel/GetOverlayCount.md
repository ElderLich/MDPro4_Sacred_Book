# Duel.GetOverlayCount

## Signature

```lua
Duel.GetOverlayCount(int player, int s, int o) -> int
```

## Description

返回以player来看的指定位置的所有叠放的卡的数量
s代表以player来看的自己的位置，o代表以player来看的对方的位置

## Parameters

- `player` `int`
- `s` `int`
- `o` `int`

## Returns

- `int`
