# Duel.SelectOption

## Signature

```lua
Duel.SelectOption(int player, int desc1, ... any) -> int
```

## Description

Shows player a list of description ids and returns the zero-based index of the selected option.
The selected description id is also announced to the client.

## Parameters

- `player` `int`
- `desc1` `int`
- `...` `any`

## Returns

- `int`
