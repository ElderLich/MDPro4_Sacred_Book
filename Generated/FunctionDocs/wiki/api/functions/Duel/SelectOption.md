# Duel.SelectOption

## Signature

```lua
Duel.SelectOption(int player, int desc1, ... any) -> int
```

## Description

让玩家选择选项，从第二个参数开始，每一个参数代表一条选项
返回选择的选项的序号(从0开始)

## Parameters

- `player` `int`
- `desc1` `int`
- `...` `any`

## Returns

- `int`
