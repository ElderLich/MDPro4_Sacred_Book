# Duel.ConfirmExtratop

## Signature

```lua
Duel.ConfirmExtratop(int player, int count) -> void
```

## Description

Reveals count cards from the top of player's Extra Deck to the client, skipping face-up Pendulum cards tracked at the Extra Deck top.

## Parameters

- `player` `int`
- `count` `int`
