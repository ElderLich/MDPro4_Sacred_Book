# Duel.AnnounceNumber

## Signature

```lua
Duel.AnnounceNumber(int player, int number, ... any) -> int,int
```

## Description

让玩家player宣言一个数字
从第二个参数开始，每一个参数代表一个可宣言的数字
第一个返回值是宣言的数字，第二个返回值是宣言数字在所有选项中的位置

## Parameters

- `player` `int`
- `number` `int`
- `...` `any`

## Returns

- `int`
- `int`
