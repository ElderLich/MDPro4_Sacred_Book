# Effect.SetCode

## Signature

```lua
Effect.SetCode(Effect e, int code) -> void
```

## Description

Sets e's code. For triggered effects this is usually an event code; for continuous effects it is the effect code being applied.

## Parameters

- `e` `Effect`
- `code` `int`
