# Effect.SetOwnerPlayer

## Signature

```lua
Effect.SetOwnerPlayer(Effect e, int player) -> void
```

## Description

Sets e's owner player to player.
Only player values 0 and 1 are accepted; any other value leaves the effect unchanged.

## Parameters

- `e` `Effect`
- `player` `int`
