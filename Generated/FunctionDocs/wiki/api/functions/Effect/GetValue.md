# Effect.GetValue

## Signature

```lua
Effect.GetValue(Effect e) -> function|int
```

## Description

Returns e's value field. For function-valued effects this is the stored callback; otherwise it is the stored integer value.

## Parameters

- `e` `Effect`

## Returns

- `function|int`
