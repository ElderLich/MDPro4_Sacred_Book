# Effect.SetProperty

## Signature

```lua
Effect.SetProperty(Effect e, int prop1, [int prop2]) -> void
```

## Description

Sets e's property flags. prop1 holds the normal effect property flags; prop2 is used for the second property word when needed.

## Parameters

- `e` `Effect`
- `prop1` `int`
- `prop2` `int` optional
