# Effect.SetCondition

## Signature

```lua
Effect.SetCondition(Effect e, function con_func) -> void
```

## Description

Sets e's condition callback. The callback decides whether the effect can apply or be activated in the current context.

## Parameters

- `e` `Effect`
- `con_func` `function`
