# Group.__sub

## Signature

```lua
Group.__sub(Group|Card left, Group|Card right) -> Group
```

## Description

Returns a new Group containing cards from the left operand that are not in the right operand.

## Parameters

- `left` `Group|Card`
- `right` `Group|Card`

## Returns

- `Group` - A new group with cards from left that are not in right.
