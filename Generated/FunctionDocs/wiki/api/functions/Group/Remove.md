# Group.Remove

## Signature

```lua
Group.Remove(Group g, function f, [Card|nil ex], ... any) -> void
```

## Description

Remove all cards from g that satisfy the filter condition f and not equal to ex, the fourth parameter starts with the extra argument

## Parameters

- `g` `Group`
- `f` `function`
- `ex` `Card|nil` optional
- `...` `any`
