# Group.SearchCard

## Signature

```lua
Group.SearchCard(Group g, function f, ... any) -> Card
```

## Description

过滤函数，返回g中满足筛选条件f的第一张卡，若没有则返回nil，从第3个参数开始为额外参数

## Parameters

- `g` `Group`
- `f` `function`
- `...` `any`

## Returns

- `Card`
