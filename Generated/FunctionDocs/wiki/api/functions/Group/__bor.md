# Group.__bor

## Signature

```lua
Group.__bor(Group|Card left, Group|Card right) -> Group
```

## Description

Bitwise-or/union operator for Group/Card operands. It uses the same core handler as Group.__add.

## Parameters

- `left` `Group|Card`
- `right` `Group|Card`

## Returns

- `Group` - A new group containing cards from both operands.
