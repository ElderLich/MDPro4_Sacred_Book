# bit.extract

## Signature

```lua
bit.extract(int r, int field, [int width]) -> int
```

## Description

Extracts width bits from r starting at bit field. width defaults to 1.

## Parameters

- `r` `int`
- `field` `int`
- `width` `int` optional

## Returns

- `int` - The extracted bit field.
