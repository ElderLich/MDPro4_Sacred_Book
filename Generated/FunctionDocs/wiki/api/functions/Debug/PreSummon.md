# Debug.PreSummon

## Signature

```lua
Debug.PreSummon(Card c, int sum_type, [int sum_location]) -> void
```

## Description

Sets c's stored summon information to summon_type plus optional summon_location in the high word.

## Parameters

- `c` `Card`
- `sum_type` `int`
- `sum_location` `int` optional - default: 0
