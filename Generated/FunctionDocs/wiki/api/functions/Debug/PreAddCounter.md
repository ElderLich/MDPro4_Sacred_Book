# Debug.PreAddCounter

## Signature

```lua
Debug.PreAddCounter(Card c, int counter_type, [int count]) -> void
```

## Description

Adds count counters of countertype directly to c for field setup; count defaults to 1.

## Parameters

- `c` `Card`
- `counter_type` `int`
- `count` `int` optional - default: 0
