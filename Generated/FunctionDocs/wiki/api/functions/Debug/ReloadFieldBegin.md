# Debug.ReloadFieldBegin

## Signature

```lua
Debug.ReloadFieldBegin(int flag, [int rule]) -> void
```

## Description

Clears the duel and starts a field reload with duel option flag and optional rule; when rule is omitted, obsolete ruling flags choose rule 1, otherwise the current rule is used.

## Parameters

- `flag` `int`
- `rule` `int` optional
